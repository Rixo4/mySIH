# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Computational biology researchers, pharmacology researchers, neuroscience researchers, and biotech research teams.

## Product Purpose

Computational neuropharmacology research platform for configuring drug evaluation experiments, simulating ion-channel and neural-network behavior, executing C++/CUDA simulations through a FastAPI backend, inspecting dose-response results, reviewing scientific reports, and comparing historical runs.

## Positioning

Immersive, highly professional scientific research workstation where the biophysical biological microcircuit visualization is the primary instrument, while controls and scientific telemetry are revealed progressively via translucent floating edge overlays.

## Operating Context

Professional scientific workstation operating in desktop research environments. Features full-viewport 2D Canvas microcircuit visualizations with real-time signal cascades, live assay evaluation, risk level scoring, activity ledgers, run history tracking, and side-by-side run comparison.

## Capabilities and Constraints

- **Confirmed Capabilities**: Configure drug dose evaluation experiments, simulate ion-channel gating (Na⁺, K⁺, Ca²⁺) and receptor dynamics (AMPA, NMDA, GABA-A, GABA-B), inspect dose-response curves, execute C++/CUDA backend simulations via FastAPI, review scientific reports, compare experiments.
- **Constraints**: Pure web frontend (React + Vite + TailwindCSS + TypeScript); backend API integration with FastAPI, Python, SQLite, C++/CUDA simulation engine. Zero modifications to backend architecture, SQLite schema, CUDA solvers, or API contracts.

## Brand Commitments & Design Character

- **Name**: Silicon Patient — Computational Neuropharmacology Research Console
- **Design Character**: Scientific, sophisticated, spatial, precise, premium, restrained, technologically advanced, research-instrument feeling.
- **Visual Reference Inspiration**: Genomex/Solenest-style biotech dashboard composition and progressive revelation interaction patterns (not a direct copy).

## Anti-References

- Generic SaaS dashboard
- Card-grid dashboard
- Excessive glassmorphic blur
- Generic AI-generated purple gradients
- Cramped layouts
- Excessive rounded cards
- Decorative animations with no purpose
- Flat 2D diagrams pretending to be 3D
- Infrastructure/admin dashboards
- Excessive backend telemetry or server connectivity badges

## Product Principles

1. **Biological Visualization as Core Instrument**: The microcircuit simulation fills 100% of the stage; UI panels float as translucent glass overlays without subtracting viewport width.
2. **Progressive Revelation**: Information and controls appear when needed via cursor-sensitive edge corridors or tab triggers.
3. **Single Active Panel Focus**: Only one major feature panel opens at a time to prevent cognitive overload and maintain spatial clarity.
4. **Authentic Scientific Integrity**: Model views and conceptual metrics are explicitly labeled; real backend values are displayed faithfully without dummy fallbacks or fake telemetry.

## Accessibility & Inclusion

Dark-mode scientific workspace optimized for desktop research displays with high-contrast typography (Inter, JetBrains Mono), keyboard navigation support (ESC panel dismiss, Ctrl+K command palette), and clear status indicators.
